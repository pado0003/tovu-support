# Tovu – IPTV Player · Support

Tovu ist ein Media Player für iPhone, iPad, Mac (Apple Silicon), Apple TV und Android.
**Tovu liefert keine Inhalte.** Du verbindest deine eigene, legale Quelle (Xtream-Zugang oder M3U-Playlist).

## Erste Schritte
1. Tovu öffnen → **Quelle verbinden**.
2. Xtream: Server-Adresse, Benutzername und Passwort deines Anbieters eintragen – oder **„Ich habe nur einen Link (M3U)“** wählen und die Playlist-URL einfügen.
3. Live TV, Filme und Serien erscheinen automatisch.

**Zum Ausprobieren** gibt es eine Demo-Playlist mit frei lizenzierten Testvideos:
`https://raw.githubusercontent.com/pado0003/tovu-support/main/demo/tovu-demo.m3u`

## Häufige Fragen
- **Ein Sender startet nicht.** Meist ist der Sender beim Anbieter gerade offline oder alle Verbindungen deines Zugangs sind belegt. Einstellungen → Sender-Check zeigt defekte Sender.
- **Ruckeln.** Einstellungen → Puffer auf „Stabil“ stellen.
- **TV-Guide fehlt.** Einstellungen → TV-Guide → „Jetzt aktualisieren“, oder im Sender-Menü „TV-Guide zuordnen…“.
- **Datenschutz:** siehe [Datenschutzerklärung](PRIVACY.md).
